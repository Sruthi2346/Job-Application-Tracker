# Job Application Tracker

A Full Stack Web Application developed using HTML, CSS, JavaScript, Python (FastAPI), SQLAlchemy, and SQLite.

## Features

- Add Job Applications
- View Applications
- Update Applications
- Delete Applications
- Search by Company
- Filter by Status
- Sort Applications
- Dashboard Statistics
- Responsive UI

## Technologies Used

- HTML5
- CSS3
- JavaScript
- Python
- FastAPI
- SQLAlchemy
- SQLite

## Installation

```bash
pip install -r requirements.txt
```

Run Backend

```bash
cd backend
uvicorn main:app --reload
```

Open

```
frontend/index.html
```
